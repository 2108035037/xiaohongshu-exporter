# 小红书帖子完整提取之神

将小红书帖子与评论整理成便于阅读、保存和分析的文件。支持单篇提取、搜索结果自动连续提取，以及 Word、CSV、Markdown 和图片、表情、视频等资源导出。

### 主要功能

- **单篇与批量提取**：打开帖子可单独导出；输入关键词搜索后，自动依次处理搜索结果中的帖子，支持随时停止并打包已保存的内容。
- **清晰的 Word 排版**：保留帖子正文、评论、昵称、时间和点赞数；支持回复缩进、分隔线和图片排版，突出正文，淡化辅助信息。
- **评论筛选与去重**：支持点赞数门槛、低信息评论过滤和重复评论去重，对“点点”机器人的部分重复回复进行合并。
- **按需导出**：基础导出为 Word；可独立开启图片与表情、完整信息 CSV、Markdown。CSV 为单个文件，整合帖子、入选评论及可获取的公开用户资料。
- **媒体分类保存**：分别保存图片与表情；尝试提取可访问的视频、动图原文件，视频帖的评论仍整理为文档。
- **缓存复用**：同一任务中切换导出选项，可复用已采集的数据，按需补充缺失资料，减少重复扫描。
- **简洁的悬浮界面**：支持拖拽、折叠、操作间隔设置及帖子保存进度显示。

### 使用方法

安装脚本后打开小红书网页版。根据需要设置操作间隔、评论筛选条件和附加导出选项，再选择单篇采集或关键词搜索批量采集。结束后下载文档或打包文件。

### 使用说明

本脚本为非官方工具，目前处于持续测试和维护阶段。“完整提取”指尽可能保存当前账号与页面能够访问、加载的信息，不保证获取平台隐藏、删除或限制访问的内容。

部分时间由页面相对时间推算，精度受原始显示方式限制。视频、动图和用户资料的获取也可能受资源地址、登录状态及平台限制影响。

自动连续访问可能触发平台限制，任何操作间隔都不保证账号安全。出现验证、访问异常或登录失效时，请停止采集。请合理使用导出内容，尊重作者版权及用户隐私，不要公开上传自己的登录凭据、缓存数据或他人个人资料。
